墨伴

一款基于 Kotlin + Jetpack Compose 打造的 Android 阅读器：本地书籍（TXT / EPUB / MOBI / AZW3 / FB2 / CBZ / CBR / CB7）与在线书源一体，内置多模式翻页、AI 智能助手、大模型朗读、词典笔记、阅读统计与局域网 Web 端，全部数据本地存储。

Kotlin Jetpack Compose Room 数据库 MMKV 偏好 AI (OpenAI 兼容) 局域网 Web 端 纯本地存储 · 无账号

快速开始Quick Start

三种方式把书装进书架：

导入本地书籍 — 书架空态点击「导入本地书籍或字体」，支持 TXT / EPUB / MOBI / AZW3 / FB2 及漫画 CBZ / CBR / CB7。也可通过右上角悬浮按钮随时导入。
在线书源搜书 — 「我的 → 书源管理」订阅书源后，通过搜索 / 分类把在线书籍加入书架并缓存。
电脑传输 — 开启局域网 Web 服务，在电脑浏览器打开手机地址，直接网页阅读 / 上传书籍与字体。

六种翻页动画

  • 滑盖翻页 — 当前页像盖子一样滑开露出下一页；回退时上一页从左侧盖入，带边缘阴影。
  • 交互翻页 — 跟手平移 + x 轴半速视差 + 整块蒙板渐变，前进回退可随时反向，无限连续拖动。
  • 平滑翻页 — 上一页 / 当前页 / 下一页三页并排整体平移，手指拖到哪页翻到哪页。
  • 垂直翻页 — 上下滚动式翻页，支持章尾上滑 / 章首下拉跨章续读。
  • 仿真翻页 — 纸张卷曲效果，还原实体书翻页手感。
  • 禁用动画 — 点击热区 / 拖动直接换页，无动画。

滑盖 / 交互 / 平滑三种横向动画均采用「三页流水线」连续交互：手指左右拖动页面跟手平移，松手按位移与速度自动吸附，一次拖动可连续跨越多页；到达章节边界时提供阻尼外拉回弹。另可选 7 种动画插值器（线性 / 回弹 / 减速 / 加速 / 预判等）。

密钥管理对话 AI / 大模型朗读 / 文生图填过的 Key 按接口归一收集
  • 章节总结 / 全书速读 — 快速掌握剧情脉络，长书也不怕迷路。

  • 排版优化 / 内容净化 — AI 修正错字与格式、净化广告噪音，保留版权与简介等关键内容。
  • 生僻字注音 / 自动打标 — 智能注音与标签，重打标前会提醒避免覆盖原始信息。
  • AI 技能管理 — 自定义提示词技能，扩展专属阅读助手。
